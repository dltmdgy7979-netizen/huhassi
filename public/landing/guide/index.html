컴퓨터로 15분 · 무료

받은 묶음을 올려
주소 만들기

묶음 하나를 끌어다 놓으면 이름.pages.dev 모양의 주소가 생깁니다. Cloudflare Pages 라는 무료 호스팅을 씁니다.

시작하기 전에

컴퓨터에서 하세요. 파일을 끌어다 놓는 단계가 있어 휴대폰으로는 번거롭습니다.

화면 글자가 조금 다를 수 있습니다. 이 안내는 2026년 11월 Cloudflare 공식 문서를 보고 적었습니다. 화면은 영어로 나올 수 있고, 단추 이름이 바뀌었을 수도 있습니다. 아래에 적은 영어 단추 이름과 비슷한 것을 찾아 누르시면 됩니다.

가입이 한 번 필요합니다. Cloudflare 계정은 가게 주인 본인 이메일로 만드세요. 홈페이지의 주인이 그 계정이 됩니다.

Steps

차례대로 따라 하기

  1. 올리기용 묶음 받기

    만들기 화면 맨 아래 13번 "올리기 · 검색 · 카톡 공유"에서 올리기용 묶음 받기 를 누릅니다. homepage.zip 이 내려옵니다.

    압축을 풀지 마세요. zip 그대로 올립니다. 안에는 홈페이지 파일(index.html)과 카톡 공유 그림(og.jpg)이 들어 있습니다.

  2. Cloudflare 가입하고 들어가기

    아래 주소로 가서 이메일로 가입합니다. 가입 뒤 받은 메일에서 인증 링크를 한 번 눌러야 합니다.

    https://dash.cloudflare.com/sign-up

  3. 새 Pages 프로젝트 만들기

    왼쪽 메뉴에서 Workers & Pages 를 누르고, Create application → Pages → Use direct upload 순서로 들어갑니다.

    화면에 따라 마지막 단추가 Drag and drop your files 로 나오기도 합니다. "Git 연결"이 아니라 파일을 직접 올리는 쪽을 고르면 됩니다.

  4. 프로젝트 이름 정하기

    이름 칸에 영어 소문자·숫자·하이픈(-)으로 가게 이름을 적습니다. 이 이름이 주소가 됩니다.

    sodam-sikdang  →  https://sodam-sikdang.pages.dev
    이미 누가 쓰는 이름이면 뒤에 글자가 덧붙을 수 있습니다. 주소는 6번에서 화면에 나오는 것을 그대로 믿으세요.

  5. 묶음 끌어다 놓기

    1번에서 받은 homepage.zip 을 화면의 점선 상자에 끌어다 놓고, 파일 목록에 index.html 이 보이면 Deploy site (또는 Save and Deploy) 를 누릅니다.

  6. 주소 확인하기

    잠시 뒤 완료 화면에 …pages.dev 주소가 나옵니다. 눌러서 홈페이지가 뜨는지 휴대폰으로도 열어 보세요. 처음 몇 분은 안 열릴 수 있습니다.

  7. 카톡 공유 그림 연결하기 (한 번만)

    주소를 알게 됐으니 한 번 더 올려야 카톡으로 보냈을 때 그림이 같이 뜹니다.

    • 만들기 화면에서 기존 파일 불러오기 로 아까 받은 homepage.zip 을 엽니다.
    • 13번 홈페이지 주소 칸에 6번의 주소를 넣습니다.
    • 올리기용 묶음 받기 를 다시 누릅니다.
    • Cloudflare 에서 방금 만든 프로젝트로 들어가 Create deployment (새 배포) 를 누르고 새 묶음을 올립니다.
Later

올린 뒤에

  • 메뉴나 가격을 바꾸고 싶을 때 만들기 화면에서 기존 파일 불러오기로 묶음을 열어 고치고, 다시 받아서 7번처럼 새 배포로 올리면 됩니다. 주소는 그대로입니다.
  • 내 도메인(예: 우리가게.kr)을 쓰고 싶을 때 도메인을 산 뒤 Cloudflare 프로젝트의 Custom domains 에서 연결합니다. 도메인을 산 업체 쪽에서도 설정할 것이 있어, 이 안내에서는 다루지 않습니다.
  • 지도에 내 홈페이지 주소 넣기 네이버 스마트플레이스와 카카오맵 매장 정보의 "홈페이지" 칸에 6번 주소를 넣어 두면, 지도에서 가게를 본 손님이 바로 넘어옵니다.
  • 묶음을 잃어버리지 마세요 마지막으로 올린 homepage.zip 을 보관해 두세요. 고칠 때 그 파일에서 다시 시작합니다.
