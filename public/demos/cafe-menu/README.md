# 카페 메뉴판 (cafe-menu)

사진 없이 글자만으로 보이는 **카페 메뉴판** 틀입니다.
화면으로 보여 주어도 되고, **A4 한 장으로 인쇄**해 매장에 두어도 됩니다.

- 파일은 **`template.html` 하나**뿐입니다. 바깥에서 불러오는 글꼴·그림·라이브러리가 없습니다.
- 설치할 것도, 빌드할 것도 없습니다. 파일을 더블클릭하면 그대로 열립니다.
- 라이선스 MIT. 고쳐 쓰셔도 되고, 팔아도 됩니다.
- 들어 있는 카페 이름·메뉴·가격은 **모두 지어낸 예시**입니다. 반드시 바꿔 주세요.

### 글을 고치는 자리를 왜 HTML 안에 두었나
이 틀은 **주석 칸이 달린 HTML 을 직접 고치는 방식**입니다.
메뉴판은 "묶음 → 메뉴 이름 → 설명 → HOT 값 → ICE 값" 이 한 줄에 나란히 붙어 있는 글입니다.
이걸 설정 칸으로 빼내면 값이 두 개씩 늘어선 목록이 되어 어느 숫자가 HOT 인지 헷갈립니다.
HTML 에 그대로 두면 **화면에서 보이는 순서가 파일에서 보이는 순서**와 같아서,
고칠 줄을 눈으로 바로 찾을 수 있습니다.
고칠 자리마다 `【1】`부터 `【5】`까지 번호를 붙여 두었습니다. `【` 를 찾으면 차례로 나옵니다.

---

## 1단계. 파일을 엽니다

1. 이 폴더의 `template.html` 을 글 편집기로 엽니다.
   (윈도는 **메모장**, 맥은 **텍스트 편집기**)
2. 같은 파일을 **더블클릭**해 브라우저로도 열어 둡니다.
   고치고 저장한 뒤 브라우저에서 새로 고치면 바로 바뀝니다.

## 2단계. 색과 글꼴을 바꿉니다 (한 군데)

1. 파일 맨 위쪽에서 `███ 여기만 바꾸세요 ███` 칸을 찾습니다.
2. `--point` 줄의 색 코드를 바꿉니다. 묶음 제목과 ‘시그니처’ 표시 색이 함께 바뀝니다.
   예) 주황 `#FF6A13` / 파랑 `#2F6FED` / 초록 `#1F9D74` / 짙은 갈색 `#6B4A2F`
3. 글꼴을 바꾸려면 `--font` 줄 맨 앞에 `"글꼴이름",` 을 넣습니다.
4. **이 칸 밖의 CSS 는 손대지 않아도 됩니다.** 인쇄 모양도 자동으로 따라갑니다.

## 3단계. 메뉴를 바꿉니다 (번호 순서대로)

1. `【1】` 탭 제목 — `<title>` 과 `description` 에 카페 이름을 넣습니다.
2. `【2】` 카페 이름과 그 아래 한 줄(한 줄 소개 · 주소).
3. `【3】` 메뉴 — 아래 규칙 넷만 알면 됩니다.
   - `<li> … </li>` 한 덩어리가 **메뉴 한 줄**입니다. 복사해 늘리고, 통째로 지워 줄입니다.
   - 숫자 두 개 중 **왼쪽이 HOT, 오른쪽이 ICE** 값입니다.
   - 한쪽만 파는 메뉴는 그 자리에 `<span class="m-dash">–</span>` 를 그대로 둡니다.
   - 자랑할 메뉴는 `<li>` 를 `<li class="m-sig">` 로 바꾸면 **시그니처** 표시가 붙습니다.
4. 묶음(커피 / 논커피 / 디저트)을 더 만들려면
   `<section class="m-group"> … </section>` 하나를 복사해 아래에 붙이고 `<h2>` 제목을 바꿉니다.
5. `【4】` 원산지와 알레르기 안내 — **실제로 쓰는 것**으로 바꿔 주세요. 법으로 붙여야 하는 글입니다.
6. `【5】` 영업시간과 전화번호.
7. 맨 아래 "지어낸 예시입니다" 한 줄은 **지우세요.**

## 4단계. A4 한 장으로 인쇄합니다

1. 브라우저에서 파일을 열고 `Ctrl+P` (맥은 `Cmd+P`) 를 누릅니다.
2. 인쇄 창에서 **용지 A4**, **방향 세로**, **배율 100%** 로 맞춥니다.
3. **머리글/바닥글**(날짜·주소가 찍히는 것)을 **끕니다.**
4. 미리보기가 `1 / 1` 이면 한 장에 떨어진 것입니다.
   `1 / 2` 로 나오면 메뉴를 두세 줄 줄이거나 배율을 95% 로 내립니다.
5. ‘프린터’ 대신 **PDF 로 저장**을 고르면 그대로 PDF 메뉴판이 됩니다.

## 5단계. 필요 없는 칸을 지웁니다

지울 때는 `<section ...>` 부터 짝이 되는 `</section>` 까지 **통째로** 지우세요.

| 필요 없으면 | 지울 것 |
|---|---|
| 디저트 묶음 (또는 다른 묶음) | 그 `<section class="m-group"> … </section>` |
| HOT/ICE 두 칸 중 하나만 쓸 때 | 아래 ‘한 칸만 쓰기’를 보세요 |
| 원산지·알레르기 안내 | `【4】` 의 `<section class="m-info"> … </section>` |
| 영업시간 | `【5】` 의 `<footer class="m-hours"> … </footer>` |
| 맨 아래 작은 글씨 | `<p class="m-fine"> … </p>` |

**한 칸만 쓰기** — 뜨거운 음료만 판다면
`<div class="m-cols">` 안의 `<span>ICE</span>` 를 지우고,
메뉴 줄마다 `<span class="m-price m-second"> … </span>` 를 지우면 값 칸이 하나가 됩니다.

## 6단계. 인터넷에 올립니다

셋 중 하나만 하면 됩니다.

1. **올리지 않고 쓰기** — 인쇄해 매장에 두거나, 파일을 메신저로 보냅니다.
2. **정적 호스팅에 끌어다 놓기** — Netlify Drop, Cloudflare Pages, GitHub Pages 같은
   무료 서비스에 이 폴더를 **그대로 끌어다 놓으면** 주소가 만들어집니다.
   파일 이름을 `index.html` 로 바꿔 두면 주소만으로 열립니다.
   그 주소를 QR 로 만들어 테이블에 붙이면 손님이 휴대폰으로 봅니다.
3. **쓰고 있는 호스팅이 있다면** FTP 로 `template.html` 하나만 올립니다.

## 7단계. 올리기 전에 눈으로 확인합니다

1. 브라우저 창을 **휴대폰만큼 좁게** 줄여 보고 값이 밀리지 않는지 봅니다.
2. 값이 빠진 줄, HOT/ICE 가 뒤바뀐 줄이 없는지 한 줄씩 봅니다.
3. 원산지·알레르기 안내가 **실제와 맞는지** 다시 봅니다.
4. 인쇄 미리보기가 `1 / 1` 인지 봅니다.
5. "지어낸 예시입니다" 문장이 **하나도 남지 않았는지** 다시 봅니다.
