칸에 주소나 글을 넣으면 그 자리에서 QR 코드가 그려집니다. PNG 로 내려받거나 그림째 복사할 수 있고, 적은 글은 아무 곳에도 올라가지 않습니다. Put a link or some text in the box and the code is drawn right here. Save it as a PNG or copy the image itself — and nothing you type is uploaded anywhere.
