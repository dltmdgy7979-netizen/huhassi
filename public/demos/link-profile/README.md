# 링크 프로필 (link-profile)

SNS 프로필에 걸어 두는 **링크 모음 한 장**입니다.
이름·한 줄 소개·링크 단추 여러 개가 세로로 놓입니다.
단추는 손가락으로 누르기 좋게 **48px 이상** 높이로 잡아 두었습니다.

- 파일은 **`template.html` 하나**뿐입니다. 바깥에서 불러오는 글꼴·그림·라이브러리가 없습니다.
- 설치할 것도, 빌드할 것도 없습니다. 파일을 더블클릭하면 그대로 열립니다.
- 라이선스 MIT. 고쳐 쓰셔도 되고, 팔아도 됩니다.
- 들어 있는 이름·링크·메일 주소는 **모두 지어낸 예시**입니다. 반드시 바꿔 주세요.
- 누가 눌렀는지 세거나 기록하는 코드가 **없습니다.**

### 글을 고치는 자리를 왜 설정 덩어리로 두었나
이 틀만은 **HTML 을 건드리지 않고 설정 덩어리(`PROFILE`) 하나만 고치는 방식**입니다.
이 쪽의 글은 `이름 / 한 줄 소개 / (제목 · 부제 · 주소)` 가 **똑같은 모양으로 반복**됩니다.
반복되는 글은 목록으로 모아 두는 쪽이 훨씬 편합니다.
링크를 늘릴 때 **한 줄을 복사**하면 되고, 줄일 때 **한 줄을 지우면** 됩니다.
HTML 태그를 열고 닫는 짝을 맞출 일이 없어서, 실수로 모양이 깨지지 않습니다.

---

## 1단계. 파일을 엽니다

1. 이 폴더의 `template.html` 을 글 편집기로 엽니다.
   (윈도는 **메모장**, 맥은 **텍스트 편집기**)
2. 같은 파일을 **더블클릭**해 브라우저로도 열어 둡니다.
   고치고 저장한 뒤 새로 고치면 바로 바뀝니다.

## 2단계. 색과 모양을 바꿉니다 (한 군데)

1. 파일 위쪽에서 `███ 여기만 바꾸세요 ① 색과 모양 ███` 칸을 찾습니다.
2. `--point` 줄의 색 코드 **하나만** 바꿉니다.
   바탕·단추 테두리·꽉 찬 단추 색이 **모두 이 한 줄에서 만들어집니다.**
   예) 주황 `#FF6A13` / 파랑 `#2F6FED` / 초록 `#1F9D74` / 보라 `#7A5AF8` / 분홍 `#E0558C`
3. 단추를 알약 모양으로 하려면 `--radius` 를 `999px`,
   각진 모양으로 하려면 `0px` 로 바꿉니다.
4. 글꼴을 바꾸려면 `--font` 줄 맨 앞에 `"글꼴이름",` 을 넣습니다.
5. **이 칸 밖의 CSS 는 손대지 않아도 됩니다.**

## 3단계. 글과 링크를 바꿉니다 (한 군데)

1. 조금 아래에서 `███ 여기만 바꾸세요 ② 글과 링크 ███` 칸을 찾습니다.
   거기 있는 `var PROFILE = { … };` 한 덩어리가 이 쪽의 글 **전부**입니다.
2. `initial` — 둥근 자리에 보일 **한 글자**입니다. 이름의 한 글자를 넣으면 됩니다.
3. `name` — 이름. 브라우저 탭 제목도 여기서 자동으로 따라갑니다.
4. `bio` — 한 줄 소개.
5. `links` 의 줄 하나가 **단추 하나**입니다. 칸은 네 개입니다.
   - `title` 단추에 크게 보일 제목
   - `note` 그 아래 작게 보일 한 줄 (지우고 싶으면 `note:"",` 로 비웁니다)
   - `url` 눌렀을 때 갈 주소. 메일은 `mailto:내주소` 로 적습니다
   - `main:true` 꽉 찬 색으로 보일 **가장 보여 주고 싶은 링크 하나**. 한 줄에만 붙입니다
6. `footer` — 맨 아래 작은 글씨. 줄을 나누려면 `\n` 을 넣습니다.
   **두 번째 줄의 "지어낸 예시입니다" 문장은 지우세요.**
7. 고칠 때 지키는 것 **둘**뿐입니다.
   - **큰따옴표 `" "` 안의 글자만** 바꿉니다. 따옴표를 지우지 마세요.
   - 줄 끝의 **쉼표 `,`** 를 지우지 마세요. 마지막 줄만 쉼표가 없습니다.
8. 화면이 하얗게만 나오면 거의 **따옴표나 쉼표를 하나 빠뜨린 것**입니다.
   방금 고친 줄을 다시 보세요.

## 4단계. 링크를 늘리거나 줄입니다

**늘리기** — `links` 안의 줄 하나를 복사해 아래에 붙이고, 위 줄 끝에 쉼표를 찍습니다.

```
{ title:"새 링크 제목", note:"아래 작은 글", url:"https://내주소" },
```

**줄이기** — 그 줄을 `{` 부터 줄 끝까지 **통째로** 지웁니다.
마지막 줄을 지웠다면, 새 마지막 줄의 쉼표를 지웁니다.

**순서 바꾸기** — 줄 위치를 옮기면 화면 순서도 같이 바뀝니다. 위에 있는 줄이 위에 보입니다.

## 5단계. 필요 없는 칸을 지웁니다

| 필요 없으면 | 지울 것 |
|---|---|
| 한 줄 소개 | `PROFILE` 의 `bio:"",` 로 비웁니다 |
| 둥근 글자 자리 | `<body>` 안의 `<div class="p-avatar" … ></div>` 한 줄 |
| 맨 아래 작은 글씨 | `PROFILE` 의 `footer:"",` 로 비웁니다 |
| 단추 아래 작은 글 | 그 줄의 `note:"",` 로 비웁니다 |

**사진을 넣고 싶으면** 정사각형 사진을 같은 폴더에 두고,
`<div class="p-avatar" id="p-avatar" aria-hidden="true"><b></b></div>` 를 아래로 바꿉니다.

```html
<div class="p-avatar"><img src="사진.jpg" alt="프로필 사진"></div>
```

(`id="p-avatar"` 를 지우면 글자 머리는 더 이상 채워지지 않습니다. 사진만 보입니다)

## 6단계. 인터넷에 올립니다

이 틀은 **주소를 만들어 프로필에 거는 것**이 목적이므로 2번을 권합니다.

1. **올리지 않고 보기** — 파일을 더블클릭하면 그대로 열립니다. 모양만 확인할 때 씁니다.
2. **정적 호스팅에 끌어다 놓기** — Netlify Drop, Cloudflare Pages, GitHub Pages 같은
   무료 서비스에 이 폴더를 **그대로 끌어다 놓으면** 주소가 하나 만들어집니다.
   파일 이름을 `index.html` 로 바꿔 두면 주소 뒤에 파일 이름을 붙이지 않아도 열립니다.
   그 주소를 SNS 프로필의 ‘웹사이트’ 칸에 넣습니다.
3. **쓰고 있는 호스팅이 있다면** FTP 로 `template.html` 하나만 올립니다.

## 7단계. 올리기 전에 눈으로 확인합니다

1. 브라우저 창을 **휴대폰만큼 좁게** 줄여 보고 단추가 가로로 밀리지 않는지 봅니다.
2. 단추를 **하나씩 전부 눌러** 제대로 된 곳으로 가는지 봅니다. (가장 많이 틀리는 곳입니다)
3. `Tab` 키만 눌러 끝까지 내려가며 단추마다 테두리가 보이는지 봅니다.
4. 메일 단추를 눌러 **내 주소**로 열리는지 확인합니다.
5. "지어낸 예시입니다" 문장과 `example.com` 주소가 **하나도 남지 않았는지** 다시 봅니다.
