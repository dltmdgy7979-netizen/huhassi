# 이력서·포트폴리오 (resume-page)

경력과 작업물을 한 쪽에 담은 **이력서** 틀입니다.
주소로 보내 줄 수도 있고, 단추 하나로 **A4 PDF** 로 저장해 첨부할 수도 있습니다.

- 파일은 **`template.html` 하나**뿐입니다. 바깥에서 불러오는 글꼴·그림·라이브러리가 없습니다.
- 설치할 것도, 빌드할 것도 없습니다. 파일을 더블클릭하면 그대로 열립니다.
- 라이선스 MIT. 고쳐 쓰셔도 되고, 팔아도 됩니다.
- 들어 있는 이름·회사·연락처·링크는 **모두 지어낸 예시**입니다. 반드시 바꿔 주세요.

### 글을 고치는 자리를 왜 HTML 안에 두었나
이 틀은 **주석 칸이 달린 HTML 을 직접 고치는 방식**입니다.
이력서는 사람마다 묶음 개수가 다릅니다. 회사가 두 곳인 사람도, 다섯 곳인 사람도 있고
어떤 사람은 자격증 칸이 아예 필요 없습니다.
그래서 **묶음을 복사하고 지우는 일**이 글을 고치는 일보다 잦습니다.
설정 칸에 글만 모아 두면 묶음을 지우기 어려워지므로,
화면에 보이는 순서 그대로 HTML 에 두고 `【1】`부터 `【8】`까지 번호를 붙였습니다.
파일에서 `【` 를 찾으면 고칠 자리가 차례로 나옵니다.

---

## 1단계. 파일을 엽니다

1. 이 폴더의 `template.html` 을 글 편집기로 엽니다.
   (윈도는 **메모장**, 맥은 **텍스트 편집기**)
2. 같은 파일을 **더블클릭**해 브라우저로도 열어 둡니다.
   고치고 저장한 뒤 새로 고치면 바로 바뀝니다.

## 2단계. 색과 글꼴을 바꿉니다 (한 군데)

1. 파일 맨 위쪽에서 `███ 여기만 바꾸세요 ███` 칸을 찾습니다.
2. `--point` 줄의 색 코드를 바꿉니다. 묶음 제목과 단추 색이 함께 바뀝니다.
   이력서라면 **차분한 색**이 무난합니다.
   예) 남색 `#2F4D8A` / 짙은 초록 `#1F6B52` / 짙은 회색 `#3A3A3A` / 주황 `#FF6A13`
3. 모서리를 각지게 하려면 `--radius` 를 `0px` 로 바꿉니다.
4. 글꼴을 바꾸려면 `--font` 줄 맨 앞에 `"글꼴이름",` 을 넣습니다.
5. **이 칸 밖의 CSS 는 손대지 않아도 됩니다.** 인쇄 모양도 자동으로 따라갑니다.

## 3단계. 내용을 바꿉니다 (번호 순서대로)

1. `【1】` 탭 제목 — `<title>` 과 `description` 에 내 이름과 하는 일을 넣습니다.
2. `【2】` 이름 · 한 줄 소개 · 연락처.
   메일 주소는 **두 군데** 바꿔야 합니다. `mailto:` 뒤의 주소와, 화면에 보이는 글자입니다.
   전화번호도 같습니다. `tel:` 뒤와 보이는 글자 둘 다입니다.
3. `【3】` 한 단락 소개. 필요 없으면 이 묶음을 지웁니다.
4. `【4】` 핵심 역량 — `<li>` 하나가 칸 하나입니다. **세~네 개**가 보기 좋습니다.
5. `【5】` 경력 — 회사 한 곳이 `<li>` 하나입니다. **최근 것을 맨 위**에 둡니다.
   - 안쪽 `<ul>` 의 `<li>` 가 한 일 불릿입니다.
   - 불릿은 "무엇을 해서 무엇이 얼마나 달라졌다" 로 쓰면 읽기 쉽습니다.
6. `【6】` 작업물 — 카드 하나가 `<li>` 하나입니다. **세 개**가 보기 좋습니다.
   링크는 두 군데(`href=` 와 보이는 글자) 모두 바꿉니다.
7. `【7】` 학력과 자격 — `<dt>` 가 연도, `<dd>` 가 내용입니다. 한 쌍씩 짝입니다.
8. `【8】` 맨 아래 연락 단추. 인쇄본에는 나오지 않습니다.
9. 맨 아래 "지어낸 예시입니다" 한 줄은 **지우세요.**

## 4단계. PDF 로 저장합니다

1. 브라우저에서 파일을 열고 화면 위 **‘인쇄 → PDF 로 저장’** 단추를 누릅니다.
   (단추를 지웠다면 `Ctrl+P`, 맥은 `Cmd+P`)
2. 인쇄 창에서 **용지 A4**, **방향 세로** 로 맞춥니다.
3. **머리글/바닥글**을 **끕니다.** (날짜와 주소가 종이에 찍히는 것을 막습니다)
4. **배경 그래픽**을 **끕니다.** 회색 칸과 그림 자리가 빠져 글만 깔끔히 나옵니다.
5. ‘프린터’ 대신 **PDF 로 저장**을 고릅니다.
6. 저장된 PDF 를 열어, 링크 주소가 **글자로 보이는지** 확인합니다.
   종이에서는 링크를 누를 수 없으니 주소를 글자로 같이 내보내도록 해 두었습니다.
   - 보이는 글자가 이미 주소인 링크에는 `class="r-url"` 을 붙여 두었습니다.
     그 링크는 주소가 두 번 찍히지 않습니다.
   - ‘자세히 보기’ 처럼 글자가 주소가 아닌 링크를 새로 넣으면,
     `class="r-url"` 을 붙이지 마세요. 인쇄본에 괄호로 주소가 같이 찍힙니다.

## 5단계. 필요 없는 칸을 지웁니다

지울 때는 `<section ...>` 부터 짝이 되는 `</section>` 까지 **통째로** 지우세요.

| 필요 없으면 | 지울 것 |
|---|---|
| 한 단락 소개 | `【3】` 의 `<section class="r-sec"> … </section>` |
| 핵심 역량 | `【4】` 의 `<section> … </section>` |
| 작업물 카드 | `【6】` 의 `<section> … </section>` |
| 학력과 자격 | `【7】` 의 `<section> … </section>` |
| 맨 아래 연락 단추 | `【8】` 의 `<nav class="r-contact"> … </nav>` |
| 위에 붙은 인쇄 줄 | `<div class="r-bar"> … </div>` |
| 작업물 카드의 그림 자리 | 카드 안의 `<div class="r-thumb" … ></div>` |
| 맨 아래 작은 글씨 | `<p class="r-foot"> … </p>` |

**그림을 넣고 싶으면** 그림 파일을 같은 폴더에 두고,
`<div class="r-thumb" … ></div>` 를
`<img src="그림.png" alt="무엇을 찍은 그림인지" class="r-thumb">` 로 바꿉니다.

## 6단계. 인터넷에 올립니다

셋 중 하나만 하면 됩니다.

1. **올리지 않고 쓰기** — PDF 로 저장해 메일에 첨부합니다. 가장 많이 쓰는 방법입니다.
2. **정적 호스팅에 끌어다 놓기** — Netlify Drop, Cloudflare Pages, GitHub Pages 같은
   무료 서비스에 이 폴더를 **그대로 끌어다 놓으면** 주소가 만들어집니다.
   파일 이름을 `index.html` 로 바꿔 두면 주소만으로 열립니다.
3. **쓰고 있는 호스팅이 있다면** FTP 로 `template.html` 하나만 올립니다.

> 주소를 공개해 두면 **누구나** 볼 수 있습니다.
> 전화번호나 사는 곳을 적었다면, 공개 주소에서는 지우고 PDF 에만 넣는 쪽이 안전합니다.

## 7단계. 올리기 전에 눈으로 확인합니다

1. 브라우저 창을 **휴대폰만큼 좁게** 줄여 보고 가로로 밀리는 글자가 없는지 봅니다.
2. `Tab` 키만 눌러 끝까지 내려가며 인쇄 단추·링크에 테두리가 보이는지 봅니다.
3. PDF 로 저장해 **한 장(또는 두 장)에 떨어지는지**, 글이 잘리지 않는지 봅니다.
4. 메일 단추를 눌러 **내 주소**로 열리는지 확인합니다.
5. "지어낸 예시입니다" 문장과 `example.com` 주소가 **하나도 남지 않았는지** 다시 봅니다.
