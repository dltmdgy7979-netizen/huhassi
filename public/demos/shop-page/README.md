# 가게 소개 한 장 (shop-page)

작은 가게의 **소개 글·이번 주 상품 목록·영업시간·찾아오는 길·전화번호**를
한 쪽에 담은 틀입니다. 손님에게 보낼 주소 하나가 필요할 때 씁니다.
예시로는 반찬가게를 넣어 두었지만, 목록만 바꾸면 어떤 가게에도 맞습니다.

- 파일은 **`template.html` 하나**뿐입니다. 바깥에서 불러오는 글꼴·그림·라이브러리가 없습니다.
- 설치할 것도, 빌드할 것도 없습니다. 파일을 더블클릭하면 그대로 열립니다.
- 라이선스 MIT. 고쳐 쓰셔도 되고, 팔아도 됩니다.
- 들어 있는 가게 이름·주소·전화번호·가격은 **모두 지어낸 예시**입니다.
  쓰기 전에 반드시 본인 가게 정보로 바꿔 주세요.

### 글을 고치는 자리를 왜 HTML 안에 두었나
이 틀은 **주석 칸이 달린 HTML 을 직접 고치는 방식**입니다.
가게 이야기는 두 단락, 반찬은 다섯 줄, 영업시간은 요일마다 한 줄처럼
**모양과 글이 붙어 있는** 글이라, 글만 따로 떼어 설정 칸에 모아 두면
오히려 "이 줄이 화면의 어디인지" 알기 어렵습니다.
그래서 화면에 보이는 순서 그대로 HTML 에 두고,
고칠 자리마다 `【1】`부터 `【10】`까지 번호를 붙여 두었습니다.
파일을 열고 `【` 를 찾으면 고칠 자리가 차례로 나옵니다.

---

## 1단계. 파일을 엽니다

1. 이 폴더의 `template.html` 을 글 편집기로 엽니다.
   (윈도는 **메모장**, 맥은 **텍스트 편집기**. 둘 다 그냥 됩니다)
2. 눈으로 먼저 보고 싶으면 같은 파일을 **더블클릭**해 브라우저로 여세요.
   고치고 저장한 뒤 브라우저에서 새로 고치면 바로 바뀝니다.

## 2단계. 색과 글꼴을 바꿉니다 (한 군데)

1. 파일 맨 위쪽에서 `███ 여기만 바꾸세요 ███` 라고 적힌 칸을 찾습니다.
2. `--point` 줄의 색 코드를 원하는 색으로 바꿉니다.
   이 한 줄만 바꾸면 제목줄·단추·강조 색이 **함께** 따라옵니다.
   예) 주황 `#FF6A13` / 파랑 `#2F6FED` / 초록 `#1F9D74` / 보라 `#7A5AF8`
3. 모서리를 각지게 하려면 `--radius` 를 `0px` 로 바꿉니다.
4. 글꼴을 바꾸려면 `--font` 줄의 맨 앞에 쓰고 싶은 글꼴 이름을
   `"글꼴이름",` 처럼 따옴표와 쉼표를 붙여 넣습니다.
   (보는 사람 컴퓨터에 그 글꼴이 없으면 뒤에 적힌 기본 글꼴로 보입니다)
5. **이 칸 밖의 CSS 는 손대지 않아도 됩니다.**

## 3단계. 글을 바꿉니다 (번호 순서대로)

파일에서 `【` 를 찾아 차례로 내려가면 됩니다.

1. `【1】` 탭 제목 — `<title>` 과 `description` 에 가게 이름을 넣습니다.
2. `【2】` 가게 이름 · 문 연 해 · 한 줄 소개.
3. `【3】` 쪽 안 길잡이 단추 — 글자를 묶음 제목과 맞춥니다. 아래 묶음을 지웠다면 그 줄도 같이 지웁니다.
4. `【4】` 사진 자리 — 사진을 넣는 방법은 4단계에 적었습니다.
5. `【5】` 가게 이야기 두 단락.
6. `【6】` 이번 주 상품 — `<li>` 한 덩어리가 한 줄입니다.
   복사해 늘리고, 필요 없으면 통째로 지웁니다.
   묶음 제목(`<h2>이번 주 반찬</h2>`)도 우리 가게 말로 바꾸세요.
7. `【7】` 영업시간 — 요일마다 한 줄입니다.
   쉬는 날 줄에는 `<tr class="s-off">` 처럼 `class="s-off"` 를 붙이면
   ‘휴무’ 표시가 붙습니다.
8. `【8】` 주소 · 주차 · 대중교통.
9. `【9】` 전화번호 — **두 군데**를 바꿔야 합니다.
   `href="tel:000-0000-0000"` 의 번호와, 화면에 보이는 글자의 번호 둘 다입니다.
10. `【10】` 맨 아래 한 줄 — 마지막 "지어낸 예시입니다" 문장은 **지우세요.**

## 4단계. 사진과 지도를 넣습니다 (안 넣어도 됩니다)

1. **사진**: 사진 파일을 `template.html` 과 **같은 폴더**에 둡니다.
2. `【4】` 자리의 `<figure class="s-photo"> … </figure>` 전체를 아래로 바꿉니다.
   ```html
   <figure class="s-photo"><img src="가게사진.jpg" alt="가게 바깥 모습"></figure>
   ```
   `가게사진.jpg` 는 실제 파일 이름으로, `alt` 는 사진에 무엇이 찍혔는지로 바꾸세요.
3. **지도**: 지도 서비스에서 ‘지도 퍼가기 / 공유’로 받은 코드를 복사합니다.
4. `【8】` 아래의 `<div class="s-map"> … </div>` 전체를 지우고 그 자리에 붙여넣습니다.

## 5단계. 필요 없는 칸을 지웁니다

지울 때는 `<section ...>` 부터 짝이 되는 `</section>` 까지 **통째로** 지우세요.

| 필요 없으면 | 지울 것 |
|---|---|
| 사진 | `【4】` 의 `<figure class="s-photo"> … </figure>` |
| 가게 이야기 | `【5】` 의 `<section … id="s-story"> … </section>` |
| 이번 주 상품 목록 | `【6】` 의 `<section … id="s-week"> … </section>` |
| 영업시간 | `【7】` 의 `<section … id="s-time"> … </section>` |
| 찾아오는 길 | `【8】` 의 `<section … id="s-way"> … </section>` |
| 지도만 | `【8】` 안의 `<div class="s-map"> … </div>` |
| 전화 단추 | `【9】` 의 `<section> … </section>` |

묶음을 지웠으면 `【3】` 길잡이에서 그 묶음으로 가는 `<li> … </li>` 줄도 같이 지웁니다.

## 6단계. 인터넷에 올립니다

가장 쉬운 쪽부터 적었습니다. 셋 중 하나만 하면 됩니다.

1. **올리지 않고 쓰기** — 파일을 메신저로 보내거나 USB 에 담아 보여 줍니다.
   더블클릭하면 그대로 열립니다.
2. **정적 호스팅에 끌어다 놓기** — Netlify Drop, Cloudflare Pages, GitHub Pages 같은
   무료 서비스에 이 폴더를 **그대로 끌어다 놓으면** 주소가 하나 만들어집니다.
   파일 이름을 `index.html` 로 바꿔 두면 주소 뒤에 파일 이름을 붙이지 않아도 열립니다.
3. **쓰고 있는 호스팅이 있다면** FTP 로 `template.html` 하나만 올립니다.

## 7단계. 올리기 전에 눈으로 확인합니다

1. 브라우저 창을 **휴대폰만큼 좁게** 줄여 보고, 가로로 밀리는 글자가 없는지 봅니다.
2. `Tab` 키만 눌러 끝까지 내려가며 길잡이·전화 단추에 테두리가 보이는지 봅니다.
3. 전화 단추를 눌러 전화 앱이 **내 번호**로 열리는지 확인합니다.
4. `Ctrl+P`(맥은 `Cmd+P`)로 인쇄 화면을 열어 봅니다. 사진·지도·길잡이는 빠지고
   글만 깔끔히 나옵니다. 가게 앞에 붙일 안내문으로 그냥 쓸 수 있습니다.
5. "지어낸 예시입니다" 문장이 **하나도 남지 않았는지** 다시 봅니다.
