# 공휴일 조회 MCP (Korean Holidays MCP)

클로드 대화창에서 바로 **한국 공휴일**을 물어볼 수 있게 해 주는 MCP 서버입니다.
공공데이터포털의 '특일정보' API 에 물어보고 그 답을 돌려줍니다.

- 라이선스: MIT (고쳐 쓰셔도 되고, 팔아도 됩니다)
- 필요한 것: Node 18 이상, 공공데이터포털 인증키
- 바깥 라이브러리: `@modelcontextprotocol/sdk` 하나뿐 (MIT)

---

## 준비 단계 — 하나씩 차례대로

### 1단계. 공공데이터포털에 회원가입합니다

1. 인터넷 주소창에 `data.go.kr` 을 넣고 들어갑니다.
2. 오른쪽 위 **회원가입** 을 눌러 가입하고, 다시 **로그인** 합니다.

### 2단계. '특일정보' 활용 신청을 합니다

1. 로그인한 상태에서 사이트 맨 위 검색창에 아래 글자를 그대로 넣고 찾습니다.

   ```
   공공데이터포털 특일정보
   ```

2. 결과 목록에서 **오픈 API** 쪽의 `특일 정보` 를 누릅니다.
3. 오른쪽 위 **활용신청** 단추를 누릅니다.
4. 활용목적은 `개인 공부` 처럼 간단히 적고 신청합니다.

> 승인은 보통 빨리 되지만 **곧바로는 아닙니다.** 자동 승인이면 몇 분,
> 사람이 보는 경우면 몇 시간에서 하루쯤 걸릴 수 있습니다.
> 승인 메일이 올 때까지 기다렸다가 다음 단계로 가 주세요.

### 3단계. 승인 뒤 인증키를 복사합니다

1. 포털에서 **마이페이지** 로 들어갑니다.
2. 왼쪽에서 **데이터활용 > 개발계정** 을 누릅니다.
3. 신청한 `특일 정보` 를 누릅니다.
4. 아래쪽 **일반 인증키(Decoding)** 칸의 값을 복사합니다.
   - `Encoding` 이 아니라 **`Decoding`** 쪽입니다. 둘을 바꿔 넣으면 작동하지 않습니다.

> 인증키는 **설정 파일에만** 넣습니다. 웹페이지, 블로그, 깃허브처럼
> 남이 볼 수 있는 곳에는 절대 넣지 마세요. 한 번 새면 남이 내 몫을 써 버립니다.

### 4단계. 폴더를 내려받고 설치합니다

1. 이 폴더를 내려받아 컴퓨터 아무 곳에 풀어 둡니다.
2. 그 폴더에서 터미널(명령 프롬프트)을 열고 아래를 넣습니다.

   ```
   npm install
   ```

### 5단계. 설정 파일에 넣고 클로드를 다시 켭니다

클로드 데스크톱 설정 파일(`claude_desktop_config.json`)을 열고 아래를 넣습니다.
`/내/경로/holidays/server.js` 와 `여기에_내_인증키_붙이기` 두 곳만 내 것으로 바꿉니다.

```json
{
  "mcpServers": {
    "korean-holidays": {
      "command": "node",
      "args": ["/내/경로/holidays/server.js"],
      "env": {
        "HOLIDAY_API_KEY": "여기에_내_인증키_붙이기"
      }
    }
  }
}
```

설정 파일이 있는 곳:

- 맥: `~/Library/Application Support/Claude/claude_desktop_config.json`
- 윈도: `%APPDATA%\Claude\claude_desktop_config.json`

저장한 뒤 **클로드를 완전히 끄고 다시 켭니다.**

## 도구 세 가지

| 도구 | 하는 일 | 넣는 값 |
| --- | --- | --- |
| `list_holidays` | 한 해(또는 한 해의 한 달) 공휴일 목록 | `year` (필수), `month` (선택) |
| `is_holiday` | 그 날이 공휴일인지 예/아니오 + 이름 | `date` (예: `2026-10-03`) |
| `next_holiday` | 다음 공휴일과 며칠 뒤인지 | `from` (선택, 비우면 오늘) |

### 이렇게 물어보면 됩니다

- "2026년 공휴일 전부 알려줘"
- "2026년 10월에 쉬는 날 있어?"
- "2026년 10월 3일이 공휴일이야?"
- "다음 공휴일 언제야? 며칠 남았어?"

## 알아 두면 좋은 것

- 한 번 물어본 해는 프로그램이 켜져 있는 동안 **기억**해 둡니다. 같은 해를 다시 물으면 바깥에 또 묻지 않습니다.
- 인증키가 없거나 틀리면, 터지는 대신 **한국말로 무엇이 잘못됐는지** 알려 줍니다.
- 포털이 XML 로 답하든 JSON 으로 답하든 둘 다 읽습니다.
- 물어볼 수 있는 연도는 2004년 ~ 2050년 입니다.
