# 공휴일 조회 MCP (Korean Holidays MCP)

클로드 대화창에서 바로 **한국 공휴일**을 물어볼 수 있게 해 주는 작은 프로그램입니다.
공공데이터포털의 '특일정보' API 에 물어보고 그 답을 돌려줍니다.

- 라이선스: MIT (고쳐 쓰셔도 되고, 팔아도 됩니다)
- 바깥 라이브러리: `@modelcontextprotocol/sdk` 하나뿐 (MIT)
- **공공데이터포털 인증키가 필요합니다.** 무료이지만 가입과 신청을 해야 합니다.

아래 1단계부터 9단계까지, **한 번에 한 단계씩** 그대로 따라 하면 됩니다.
2단계에서 **승인을 기다려야 하니**, 먼저 신청해 두고 나머지를 하는 편이 빠릅니다.

---

## 1단계. Node 가 깔려 있는지 확인합니다

먼저 **터미널**을 엽니다.

- **맥**: `command` + `space` 를 누르고 `터미널` 이라고 적은 뒤 `enter`
- **윈도**: 작업줄 검색창에 `명령 프롬프트` 라고 적은 뒤 누르기

창이 열리면 아래 글자를 그대로 넣고 `enter` 를 누릅니다.

```
node -v
```

**`v18.0.0` 처럼 `v` 뒤의 숫자가 18 이상으로 나오면 통과입니다.** 3단계로 가세요.

> 숫자가 꼭 18 이상이어야 합니다. 이 프로그램은 Node 에 들어 있는 `fetch` 를 쓰고,
> 그게 18판부터 들어왔기 때문입니다.

## 2단계. Node 가 없으면 깔아 줍니다

1단계에서 `command not found` 또는 `'node'은(는) ... 인식되지 않습니다` 라고 나왔거나,
숫자가 18보다 작게 나왔다면 Node 를 깔아야 합니다.

1. 인터넷 주소창에 `nodejs.org` 를 넣고 들어갑니다.
2. 큰 단추 두 개 중 **LTS** 라고 적힌 쪽을 누릅니다. (`Current` 쪽이 아닙니다)
3. 내려받은 파일을 두 번 눌러, 묻는 것마다 **다음 / 계속**을 눌러 끝까지 깝니다.
4. **터미널 창을 닫고 새로 엽니다.** (이걸 안 하면 깔아도 안 보입니다)
5. 1단계를 다시 해서 숫자가 나오는지 확인합니다.

## 3단계. 공공데이터포털에 가입합니다

1. 인터넷 주소창에 `data.go.kr` 을 넣고 들어갑니다.
2. 오른쪽 위 **회원가입** 을 눌러 가입하고, 다시 **로그인** 합니다.

## 4단계. '특일 정보' 활용 신청을 합니다

1. 로그인한 상태에서 사이트 맨 위 검색창에 아래 글자를 그대로 넣고 찾습니다.

   ```
   특일정보
   ```

2. 결과에서 **오픈 API** 쪽의 `한국천문연구원_특일 정보` 를 누릅니다.
3. 오른쪽 위 **활용신청** 단추를 누릅니다.
4. 활용목적은 `개인 공부` 처럼 간단히 적고 신청합니다.

> 승인은 보통 빨리 되지만 **곧바로는 아닙니다.** 자동 승인이면 몇 분,
> 사람이 보는 경우면 몇 시간에서 하루쯤 걸릴 수 있습니다.
> 기다리는 동안 6단계와 7단계를 먼저 해 두면 됩니다.

## 5단계. 승인 뒤 인증키를 복사합니다

1. 포털에서 **마이페이지** 로 들어갑니다.
2. 왼쪽에서 **데이터활용** → **개발계정** 을 누릅니다.
3. 신청한 `특일 정보` 를 누릅니다.
4. 아래쪽 **일반 인증키(Decoding)** 칸의 값을 복사합니다.
   - **`Encoding` 이 아니라 `Decoding` 쪽입니다.** 가장 많이 틀리는 곳입니다.
     바꿔 넣으면 작동하지 않습니다.
   - 복사할 때 **앞뒤 빈칸이나 줄바꿈이 끼지 않게** 하세요.

> ### 인증키는 절대 사람들이 볼 수 있는 곳에 넣지 마세요
>
> 인증키는 **아래 8단계의 설정 파일에만** 넣습니다.
> 웹페이지의 HTML, 블로그 글, 깃허브, 스크린샷, 남에게 보내는 메시지 —
> **어디에도 적지 마세요.** 한 번 새면 남이 내 몫의 횟수를 다 써 버리고,
> 하루 한도가 금방 바닥납니다. 이 프로그램이 키를 코드가 아니라
> 환경변수로만 받는 이유가 바로 이것입니다.

## 6단계. 이 폴더를 컴퓨터에 둡니다

1. 이 폴더(`holidays`)를 내려받아 압축을 풉니다.
2. **다시 옮기지 않을 자리**에 둡니다.
   - 맥 예시: `/Users/내이름/mcp/holidays`
   - 윈도 예시: `C:\Users\내이름\mcp\holidays`
3. **이 경로를 적어 두세요.** 8단계에서 그대로 씁니다.
   - 맥: 폴더를 `control` + 누르기 → `option` 을 누른 채 **"...의 경로 복사"**
   - 윈도: 폴더를 `shift` + 오른쪽 누르기 → **"경로로 복사"**

## 7단계. 설치 명령 한 줄을 넣습니다

터미널에서 그 폴더로 들어간 다음, 설치 명령을 넣습니다.
`cd ` (cd 다음에 빈칸 하나)를 적고, 그 뒤에 6단계에서 복사한 경로를 붙입니다.

```
cd /Users/내이름/mcp/holidays
```

```
npm install
```

`added 95 packages` 처럼 나오면 끝났습니다. 몇 초에서 몇십 초 걸립니다.

## 8단계. 설정 파일에 붙여 넣습니다

클로드 데스크톱 설정 파일에 적어 주어야 클로드가 이 프로그램을 알아봅니다.

**설정 파일이 있는 곳**

- 맥: `~/Library/Application Support/Claude/claude_desktop_config.json`
- 윈도: `%APPDATA%\Claude\claude_desktop_config.json`

**파일을 여는 가장 쉬운 방법**은 클로드 데스크톱 안에서 가는 것입니다.
`설정` → `개발자` → `설정 편집` 을 누르면 그 파일이 열립니다.

> **이 파일이 아직 없어도 괜찮습니다.** 한 번도 MCP 를 붙이지 않았다면 없는 것이 정상입니다.
> 없으면 위 경로에 `claude_desktop_config.json` 이라는 이름으로 **새로 만들면** 됩니다.
> 이름 끝이 `.json` 이어야 합니다 (`.json.txt` 가 되지 않게 조심).

**붙여 넣을 내용** — 파일이 비어 있거나 새로 만들었다면 아래를 통째로 넣습니다.

```json
{
  "mcpServers": {
    "korean-holidays": {
      "command": "node",
      "args": ["/Users/내이름/mcp/holidays/server.js"],
      "env": {
        "HOLIDAY_API_KEY": "여기에_내_인증키_붙이기"
      }
    }
  }
}
```

**내 것으로 바꿀 곳은 두 군데뿐입니다.**

1. `/Users/내이름/mcp/holidays/server.js` → 6단계 경로 + `/server.js`
2. `여기에_내_인증키_붙이기` → 5단계에서 복사한 **일반 인증키(Decoding)** 값
   (따옴표 `"` 두 개는 그대로 두고, 그 사이의 글자만 바꿉니다)

> **윈도에서는 역슬래시를 두 개씩 넣습니다.** 이걸 놓치면 설정이 깨집니다.
> ```json
> "args": ["C:\\Users\\내이름\\mcp\\holidays\\server.js"],
> ```

이미 `mcpServers` 안에 다른 것이 들어 있다면, `"korean-holidays": { ... }` 덩어리만
쉼표로 이어 붙입니다.

```json
{
  "mcpServers": {
    "이미-있던-것": { "command": "node", "args": ["..."] },
    "korean-holidays": {
      "command": "node",
      "args": ["/Users/내이름/mcp/holidays/server.js"],
      "env": { "HOLIDAY_API_KEY": "내_인증키" }
    }
  }
}
```

저장합니다.

## 9단계. 클로드를 끄고 다시 켜서 확인합니다

**창만 닫으면 안 됩니다. 완전히 종료해야 합니다.**

- 맥: `command` + `Q`, 또는 위쪽 메뉴에서 `Claude` → `Claude 종료`
- 윈도: 작업줄 오른쪽 숨은 아이콘에서 클로드를 찾아 오른쪽 누르기 → `종료`

다시 켠 뒤 **이렇게 되었는지 봅니다.**

1. 입력창 아래(또는 `설정` → `커넥터`)에 **도구 표시**가 보이고,
   눌러 보면 `list_holidays`, `is_holiday`, `next_holiday` **세 개**가 들어 있습니다.
2. 대화창에 **"2026년 공휴일 알려줘"** 라고 적어 봅니다.
3. 클로드가 도구를 써도 되는지 물으면 **허용**을 누릅니다.
4. 날짜와 요일이 줄줄이 나오면 **다 된 것입니다.**

## 안 될 때 — 실제로 겪은 것들

### ㄱ. 도구 목록에 아무것도 안 보인다

설정 파일이 클로드 눈에 안 띈 것입니다.

- 파일 **이름**이 정확히 `claude_desktop_config.json` 인지 확인합니다.
  윈도 메모장으로 만들면 `claude_desktop_config.json.txt` 가 되기 쉽습니다.
  (탐색기 → `보기` → `파일 확장명` 켜고 확인)
- 클로드를 **진짜로 종료**했는지 확인합니다. 창만 닫은 것은 종료가 아닙니다.
- 파일 안의 쉼표·중괄호가 맞는지 확인합니다. JSON 은 쉼표 하나만 틀려도 통째로 무시됩니다.

### ㄴ. 도구는 보이는데 "Cannot find package '@modelcontextprotocol/sdk'" 가 난다

7단계 `npm install` 을 안 했거나, **다른 폴더에서** 했습니다. 실제 오류는 이렇게 생겼습니다.

```
Error [ERR_MODULE_NOT_FOUND]: Cannot find package
'@modelcontextprotocol/sdk' imported from .../holidays/server.js
```

→ `server.js` 가 들어 있는 **그 폴더에서** `npm install` 을 다시 넣습니다.
그 폴더 안에 `node_modules` 라는 폴더가 생겼는지 눈으로 확인하면 확실합니다.

### ㄷ. "공공데이터포털 인증키가 설정되어 있지 않습니다" 라고 답한다

`HOLIDAY_API_KEY` 가 비어 있을 때 나오는 말입니다. 프로그램은 잘 켜졌습니다.

→ 8단계 `env` 칸이 빠졌거나 철자가 틀렸습니다. `HOLIDAY_API_KEY` 를 확인하고
설정을 고친 뒤 **클로드를 다시 종료하고 켭니다.**

### ㄹ. "인증을 거절했습니다 (HTTP 401)" 또는 "등록되지 않은 인증키입니다" 라고 답한다

키 문제입니다. 위에서부터 하나씩 확인하세요.

1. **`Decoding` 쪽 키인지** — `Encoding` 쪽을 넣으면 이 오류가 납니다. 가장 흔한 원인입니다.
2. 키 앞뒤에 **빈칸이나 줄바꿈**이 끼지 않았는지.
3. 마이페이지 → 데이터활용 → **개발계정**에 '특일 정보'가 **승인** 상태로 있는지.
   신청만 하고 승인 전이면 키는 보이지만 작동하지 않습니다.

### ㅁ. "오늘 또는 지금 쓸 수 있는 횟수를 넘겼습니다" 라고 답한다

포털은 하루에 쓸 수 있는 횟수를 정해 두었습니다 (개발계정은 적습니다).

→ 내일 다시 쓰면 풀립니다. 이 프로그램은 **한 번 물어본 해를 기억**해 두므로,
같은 해를 여러 번 물어도 포털에는 한 번만 묻습니다. 그래도 모자라면
마이페이지에서 **운영계정** 전환을 신청하면 한도가 늘어납니다.

### ㅂ. "공공데이터포털에 연결하지 못했습니다" 라고 답한다

인터넷이 끊겼거나, 회사·학교 방화벽이 막은 것입니다. 키 문제가 아닙니다.

→ 브라우저로 `data.go.kr` 이 열리는지 먼저 확인하세요.
열리는데도 안 되면 보안 프로그램이나 VPN 을 잠시 꺼 보세요.

### ㅅ. "N초 안에 답하지 않았습니다" 라고 답한다

포털이 느린 때입니다. 8초까지 기다리고 포기합니다.

→ 잠시 뒤 다시 물어보세요. 이것도 내 설정 문제가 아닙니다.

## 도구 세 가지

| 도구 | 하는 일 | 넣는 값 |
| --- | --- | --- |
| `list_holidays` | 한 해(또는 한 해의 한 달) 공휴일 목록 | `year` (필수), `month` (선택, 1~12) |
| `is_holiday` | 그 날이 공휴일인지 예/아니오 + 이름 | `date` (예: `2026-10-03`) |
| `next_holiday` | 다음 공휴일과 며칠 뒤인지 | `from` (선택, 비우면 오늘) |

### 이렇게 물어보면 됩니다

- `list_holidays` → **"2026년 공휴일 전부 알려줘"** / "2026년 10월에 쉬는 날 있어?"
- `is_holiday` → **"2026년 10월 3일이 공휴일이야?"**
- `next_holiday` → **"다음 공휴일 언제야? 며칠 남았어?"**

이어서 이렇게도 됩니다 — "올해 남은 공휴일 중에 금요일이나 월요일인 날만 골라 줘"

## 알아 두면 좋은 것

- 한 번 물어본 해는 프로그램이 켜져 있는 동안 **기억**해 둡니다. 포털 횟수를 아끼기 위한 것입니다.
  (비어 온 답은 기억하지 않습니다. 잘못 기억해서 계속 "없다"고 하면 안 되니까요)
- 물어볼 수 있는 연도는 **2004년 ~ 2050년** 입니다.
- 포털이 XML 로 답하든 JSON 으로 답하든 둘 다 읽습니다.
- `is_holiday` 는 **법정 공휴일**만 "예"라고 합니다. 식목일처럼 쉬지 않는 기념일은
  "아니요"가 됩니다. 주말이면 "다만 주말입니다" 라고 덧붙입니다.
- 무엇이 잘못되었든 **프로그램이 터지지 않고 한국말로 까닭을 말해 줍니다.**
  어떤 까닭인지에 따라 다른 말이 나오도록 만들어 두었습니다.
