# 로컬 메모 MCP (Local Notes MCP)

내 컴퓨터 안의 **메모 폴더**(`.md`, `.txt`)를 클로드가 찾아보고 읽을 수 있게 해 주는 작은 프로그램입니다.

- **바깥으로 아무것도 보내지 않습니다.** 내 디스크에서 읽기만 합니다.
- **인터넷도, 가입도, API 키도 필요 없습니다.**
- **읽기만 합니다.** 파일을 고치거나 지우는 기능이 아예 없습니다.
- 라이선스: MIT (고쳐 쓰셔도 되고, 팔아도 됩니다)
- 바깥 라이브러리: `@modelcontextprotocol/sdk` 하나뿐 (MIT)

아래 1단계부터 7단계까지, **한 번에 한 단계씩** 그대로 따라 하면 됩니다.
컴퓨터에 뭔가 설치해 본 적이 없어도 괜찮습니다.

---

## 1단계. Node 가 깔려 있는지 확인합니다

먼저 **터미널**을 엽니다.

- **맥**: `command` + `space` 를 누르고 `터미널` 이라고 적은 뒤 `enter`
- **윈도**: 작업줄 검색창에 `명령 프롬프트` 라고 적은 뒤 누르기

검은(또는 흰) 창이 열리면 아래 글자를 그대로 넣고 `enter` 를 누릅니다.

```
node -v
```

**`v18.0.0` 처럼 `v` 뒤의 숫자가 18 이상으로 나오면 통과입니다.** 2단계로 가세요.

## 2단계. Node 가 없으면 깔아 줍니다

1단계에서 `command not found` 또는 `'node'은(는) ... 인식되지 않습니다` 라고 나왔거나,
숫자가 18보다 작게 나왔다면 Node 를 깔아야 합니다.

1. 인터넷 주소창에 `nodejs.org` 를 넣고 들어갑니다.
2. 큰 단추 두 개 중 **LTS** 라고 적힌 쪽을 누릅니다. (`Current` 쪽이 아닙니다)
3. 내려받은 파일을 두 번 눌러, 묻는 것마다 **다음 / 계속**을 눌러 끝까지 깝니다.
4. **터미널 창을 닫고 새로 엽니다.** (이걸 안 하면 깔아도 안 보입니다)
5. 1단계를 다시 해서 숫자가 나오는지 확인합니다.

## 3단계. 이 폴더를 컴퓨터에 둡니다

1. 이 폴더(`notes`)를 내려받아 압축을 풉니다.
2. **다시 옮기지 않을 자리**에 둡니다. 바탕화면보다 아래쪽을 권합니다.
   - 맥 예시: `/Users/내이름/mcp/notes`
   - 윈도 예시: `C:\Users\내이름\mcp\notes`
3. **이 경로를 적어 두세요.** 5단계에서 그대로 씁니다.
   - 맥: 폴더를 `control` + 누르기 → `option` 을 누른 채 **"...의 경로 복사"**
   - 윈도: 폴더를 `shift` + 오른쪽 누르기 → **"경로로 복사"**

## 4단계. 설치 명령 한 줄을 넣습니다

터미널에서 그 폴더로 들어간 다음, 설치 명령을 넣습니다.
`cd ` (cd 다음에 빈칸 하나)를 적고, 그 뒤에 3단계에서 복사한 경로를 붙입니다.

```
cd /Users/내이름/mcp/notes
```

```
npm install
```

`added 95 packages` 처럼 나오면 끝났습니다. 몇 초에서 몇십 초 걸립니다.
빨간 글씨가 보여도 `added ... packages` 줄이 있으면 괜찮습니다.

## 5단계. 메모 폴더 경로를 정합니다

클로드가 읽을 **메모 폴더**를 하나 정합니다. 이 폴더 **안쪽만** 읽습니다.

- 맥 예시: `/Users/내이름/Documents/메모`
- 윈도 예시: `C:\Users\내이름\Documents\메모`

3단계와 같은 방법으로 **이 폴더의 경로도 복사해 둡니다.**
아직 없으면 지금 만들고, `.md` 나 `.txt` 파일을 몇 개 넣어 두세요.

## 6단계. 설정 파일에 붙여 넣습니다

클로드 데스크톱 설정 파일에 적어 주어야 클로드가 이 프로그램을 알아봅니다.

**설정 파일이 있는 곳**

- 맥: `~/Library/Application Support/Claude/claude_desktop_config.json`
- 윈도: `%APPDATA%\Claude\claude_desktop_config.json`

**파일을 여는 가장 쉬운 방법**은 클로드 데스크톱 안에서 가는 것입니다.
`설정` → `개발자` → `설정 편집` 을 누르면 그 파일이 열립니다.

> **이 파일이 아직 없어도 괜찮습니다.** 한 번도 MCP 를 붙이지 않았다면 없는 것이 정상입니다.
> 없으면 위 경로에 `claude_desktop_config.json` 이라는 이름으로 **새로 만들면** 됩니다.
> 이름 끝이 `.json` 이어야 합니다 (`.json.txt` 가 되지 않게 조심).

**붙여 넣을 내용** — 파일이 비어 있거나 새로 만들었다면 아래를 통째로 넣습니다.

```json
{
  "mcpServers": {
    "local-notes": {
      "command": "node",
      "args": ["/Users/내이름/mcp/notes/server.js"],
      "env": {
        "NOTES_DIR": "/Users/내이름/Documents/메모"
      }
    }
  }
}
```

**내 것으로 바꿀 곳은 두 군데뿐입니다.**

1. `/Users/내이름/mcp/notes/server.js` → 3단계 경로 + `/server.js`
2. `/Users/내이름/Documents/메모` → 5단계에서 정한 메모 폴더 경로

> **윈도에서는 역슬래시를 두 개씩 넣습니다.** 이걸 놓치면 설정이 깨집니다.
> ```json
> "args": ["C:\\Users\\내이름\\mcp\\notes\\server.js"],
> "env": { "NOTES_DIR": "C:\\Users\\내이름\\Documents\\메모" }
> ```

이미 `mcpServers` 안에 다른 것이 들어 있다면, `"local-notes": { ... }` 덩어리만
쉼표로 이어 붙입니다.

```json
{
  "mcpServers": {
    "이미-있던-것": { "command": "node", "args": ["..."] },
    "local-notes": {
      "command": "node",
      "args": ["/Users/내이름/mcp/notes/server.js"],
      "env": { "NOTES_DIR": "/Users/내이름/Documents/메모" }
    }
  }
}
```

저장합니다.

## 7단계. 클로드를 끄고 다시 켜서 확인합니다

**창만 닫으면 안 됩니다. 완전히 종료해야 합니다.**

- 맥: `command` + `Q`, 또는 위쪽 메뉴에서 `Claude` → `Claude 종료`
- 윈도: 작업줄 오른쪽 숨은 아이콘에서 클로드를 찾아 오른쪽 누르기 → `종료`

다시 켠 뒤 **이렇게 되었는지 봅니다.**

1. 입력창 아래(또는 `설정` → `커넥터`)에 **도구 표시**가 보이고,
   눌러 보면 `search_notes`, `read_note`, `list_notes` **세 개**가 들어 있습니다.
2. 대화창에 **"내 메모 목록 보여줘"** 라고 적어 봅니다.
3. 클로드가 도구를 써도 되는지 물으면 **허용**을 누릅니다.
4. 파일 이름과 고친 날짜가 줄줄이 나오면 **다 된 것입니다.**

## 안 될 때 — 실제로 겪은 것들

### ㄱ. 도구 목록에 아무것도 안 보인다

설정 파일이 클로드 눈에 안 띈 것입니다.

- 파일 **이름**이 정확히 `claude_desktop_config.json` 인지 확인합니다.
  윈도 메모장으로 만들면 `claude_desktop_config.json.txt` 가 되기 쉽습니다.
  (탐색기 → `보기` → `파일 확장명` 켜고 확인)
- 클로드를 **진짜로 종료**했는지 확인합니다. 창만 닫은 것은 종료가 아닙니다.
- 파일 안의 쉼표·중괄호가 맞는지 확인합니다. JSON 은 쉼표 하나만 틀려도 통째로 무시됩니다.
  마지막 항목 뒤에는 쉼표를 **붙이지 않습니다.**

### ㄴ. 도구는 보이는데 "Cannot find package '@modelcontextprotocol/sdk'" 가 난다

4단계 `npm install` 을 안 했거나, **다른 폴더에서** 했습니다. 실제 오류는 이렇게 생겼습니다.

```
Error [ERR_MODULE_NOT_FOUND]: Cannot find package
'@modelcontextprotocol/sdk' imported from .../notes/server.js
```

→ `server.js` 가 들어 있는 **그 폴더에서** `npm install` 을 다시 넣습니다.
그 폴더 안에 `node_modules` 라는 폴더가 생겼는지 눈으로 확인하면 확실합니다.

### ㄷ. "메모 폴더가 설정되어 있지 않습니다" 라고 답한다

`NOTES_DIR` 이 비어 있을 때 나오는 말입니다. 프로그램은 잘 켜졌습니다.

→ 6단계 `env` 칸이 빠졌거나 글자가 틀렸습니다. `NOTES_DIR` 철자를 확인하고
설정을 고친 뒤 **클로드를 다시 종료하고 켭니다.**

### ㄹ. "메모 폴더를 찾을 수 없습니다: ..." 라고 답한다

경로가 틀렸거나, 폴더 이름이 바뀌었거나, 폴더를 옮긴 것입니다.

→ 메시지에 적힌 경로를 그대로 복사해 터미널에 `ls` (윈도는 `dir`) 뒤에 붙여 봅니다.
아무것도 안 나오면 경로가 틀린 것입니다. 5단계 방법으로 경로를 다시 복사해 넣습니다.
`~` 로 줄여 쓰지 말고 `/Users/...` 로 **전체 경로**를 적으세요.

### ㅁ. "메모 5개" 라고 하는데 내 메모는 더 많다

이 프로그램은 **`.md` 와 `.txt` 만** 봅니다.
`.docx`, `.hwp`, `.pdf`, `.json` 은 세지 않습니다. 숨김 폴더와 `node_modules` 도 건너뜁니다.

### ㅂ. 큰 메모를 읽으면 끝이 잘린다

맞습니다. 일부러 그렇게 해 두었습니다. 파일 하나에서 앞 512KB,
돌려주는 글자는 6만 자까지입니다. 잘렸을 때는 아래처럼 **잘렸다고 적어** 줍니다.

```
…(파일이 커서 앞 512KB만 읽었습니다 · 앞 60000글자만 보여 드립니다)
```

→ 더 보고 싶으면 메모를 여러 파일로 나누거나, 클로드에게 그 안에서
무엇을 찾을지 집어 말해 주세요.

## 도구 세 가지

| 도구 | 하는 일 | 넣는 값 |
| --- | --- | --- |
| `list_notes` | 최근에 고친 메모 목록을 날짜·크기와 함께 돌려줍니다 | `limit` (선택, 최대 200, 기본 30) |
| `search_notes` | 낱말을 찾아 파일 이름 · 줄 번호 · 앞뒤 조각을 돌려줍니다 | `keyword` (필수), `limit` (선택, 최대 40) |
| `read_note` | 메모 한 개를 읽어 내용을 돌려줍니다 | `path` (메모 폴더 기준 상대 경로) |

### 이렇게 물어보면 됩니다

- `list_notes` → **"내 메모 목록 보여줘"** / "최근에 고친 메모 열 개만 보여줘"
- `search_notes` → **"내 메모에서 '보일러' 라는 말 찾아봐"**
- `read_note` → **"`일기/2026-01.md` 읽고 세 줄로 요약해 줘"**

이어서 이렇게도 됩니다 — "지난달 메모에서 아직 안 한 일만 모아 줘"

## 안전 장치 — 무엇을 막아 두었나

이 서버는 **읽기만** 합니다. 고치거나 지우는 기능이 코드에 없습니다.
그리고 메모 폴더 밖은 아래 장치로 막아 두었습니다. (모두 직접 시험해 확인했습니다)

| 넣어 본 것 | 어떻게 되나 |
| --- | --- |
| `../../etc/passwd` | `메모 폴더 밖은 읽을 수 없습니다.` |
| `/etc/passwd` (절대 경로) | `메모 폴더 기준의 상대 경로로 적어 주세요.` |
| 폴더 밖을 가리키는 바로가기 | `바로가기가 메모 폴더 밖을 가리킵니다. 읽지 않았습니다.` |
| `.json` 등 다른 확장자 | `.md 와 .txt 파일만 읽습니다.` |
| 1MB 가 넘는 큰 파일 | 앞 512KB 만 읽고, 잘렸다고 알려 줍니다 |
| 0바이트 빈 파일 | `(내용이 없는 빈 파일입니다.)` |

- 들어온 경로를 **실제 경로로 끝까지 풀어서**(realpath) 메모 폴더 안인지 다시 확인합니다.
- 폴더를 훑을 때 바로가기는 따라가지 않습니다. 깊이 8단계, 파일 4000개까지입니다.
- 검색 결과는 최대 40건, 한 파일에서 최대 3줄까지입니다.
