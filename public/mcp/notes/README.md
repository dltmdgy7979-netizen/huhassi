# 로컬 메모 MCP (Local Notes MCP)

내 컴퓨터 안의 **메모 폴더**(`.md`, `.txt`)를 클로드가 찾아보고 읽을 수 있게 해 주는 MCP 서버입니다.
**바깥으로 아무것도 보내지 않습니다.** 디스크에서 읽기만 합니다. API 키도 필요 없습니다.

- 라이선스: MIT (고쳐 쓰셔도 되고, 팔아도 됩니다)
- 필요한 것: Node 18 이상
- 바깥 라이브러리: `@modelcontextprotocol/sdk` 하나뿐 (MIT)

---

## 준비 단계 — 하나씩 차례대로

### 1단계. Node 가 깔려 있는지 확인합니다

터미널(맥은 '터미널', 윈도는 '명령 프롬프트')을 열고 아래를 그대로 넣습니다.

```
node -v
```

`v18.0.0` 처럼 **18 이상** 숫자가 나오면 됩니다.
아무것도 안 나오거나 숫자가 18보다 작으면 `nodejs.org` 에서 **LTS** 판을 받아 깔고 다시 해 보세요.

### 2단계. 이 폴더를 내려받습니다

1. 이 폴더를 내려받아 컴퓨터 아무 곳에 풀어 둡니다.
2. 예를 들어 `/Users/내이름/mcp/notes` 처럼 둡니다. 이 경로를 **기억해 두세요.** 뒤에 씁니다.

### 3단계. 설치합니다

풀어 둔 폴더에서 터미널을 열고 아래를 넣습니다.

```
npm install
```

### 4단계. 설정 파일에 메모 폴더 경로를 넣습니다

클로드 데스크톱 설정 파일(`claude_desktop_config.json`)을 열고 아래를 넣습니다.
바꿀 곳은 두 군데입니다 — `/내/경로/notes/server.js` 와 `/내/메모/폴더`.

```json
{
  "mcpServers": {
    "local-notes": {
      "command": "node",
      "args": ["/내/경로/notes/server.js"],
      "env": {
        "NOTES_DIR": "/내/메모/폴더"
      }
    }
  }
}
```

설정 파일이 있는 곳:

- 맥: `~/Library/Application Support/Claude/claude_desktop_config.json`
- 윈도: `%APPDATA%\Claude\claude_desktop_config.json`

> 윈도에서는 경로에 역슬래시를 **두 개씩** 넣습니다.
> 예: `"C:\\Users\\내이름\\메모"`

### 5단계. 클로드를 완전히 끄고 다시 켭니다

저장한 뒤 클로드를 **창만 닫지 말고 완전히 종료**하고 다시 켭니다.
대화창에서 "메모 목록 보여줘" 라고 해 보면 바로 알 수 있습니다.

## 도구 세 가지

| 도구 | 하는 일 | 넣는 값 |
| --- | --- | --- |
| `search_notes` | 낱말을 찾아, 파일 이름 · 줄 번호 · 앞뒤 조각을 돌려줍니다 | `keyword` (필수), `limit` (선택, 최대 40) |
| `read_note` | 메모 한 개를 읽어 내용을 돌려줍니다 | `path` (메모 폴더 기준 상대 경로) |
| `list_notes` | 최근에 고친 메모 목록을 날짜와 함께 돌려줍니다 | `limit` (선택, 최대 200) |

### 이렇게 물어보면 됩니다

- "내 메모에서 '보일러' 라는 말 찾아봐"
- "최근에 고친 메모 열 개만 보여줘"
- "`일기/2026-01.md` 읽고 요약해 줘"
- "지난주에 적어 둔 아이디어 중에 쓸 만한 거 골라줘"

## 안전 장치 — 무엇을 막아 두었나

이 서버는 **읽기만** 합니다. 파일을 고치거나 지우는 기능이 아예 없습니다.
그리고 아래 장치로 메모 폴더 밖은 손대지 못하게 막아 두었습니다.

- 들어온 경로를 **실제 경로로 끝까지 풀어서**, 메모 폴더 안인지 다시 확인합니다.
- `..` 로 위 폴더를 거슬러 올라가는 경로를 거절합니다.
- **바로가기(심볼릭 링크)** 로 폴더 밖을 가리키는 것도 거절합니다 (풀린 진짜 경로를 뿌리와 비교).
- 절대 경로(`/etc/passwd` 같은 것)를 넣으면 거절합니다.
- `.md` 와 `.txt` 만 읽습니다. 다른 확장자는 아예 보지 않습니다.
- 파일 하나 **512KB** 까지, 한 번에 읽어 돌려주는 글자는 **6만 자**까지입니다.
- 폴더를 훑을 때 깊이 8단계, 파일 4000개까지입니다. 검색 결과는 최대 40건, 한 파일에서 최대 3줄입니다.
- 숨김 폴더와 `node_modules` 같은 폴더는 건너뜁니다.
